## Multiple Linear Regression - Car Data
A Machine Learning implementation of Multiple Linear Regression using Python and Scikit-learn with car data for price prediction.

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
Car dataset available through the Seaborn library.

## Workflow
1. Dataset Loading
2. Data Preparation
3. Feature Selection
4. Data Preprocessing
5. Splitting the Dataset
6. Model Training
7. Price Prediction
8. Model Evaluation

## Purpose
This repository demonstrates Multiple Linear Regression using multiple features from car data to predict car prices and evaluate the performance of the trained model.
